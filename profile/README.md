# FPV Drone in Any Game

[libfpv](https://github.com/hammerill/libfpv) is a C/C++ library that lets you inject FPV drones into games you know (inspired by [libsm64](https://github.com/libsm64/libsm64)), designed to be used with an AI.

You can access the central library repo here: https://github.com/hammerill/libfpv

This organization is to contain other miscellaneous repos and future game mods.
